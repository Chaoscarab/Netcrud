NETCRUD BACKEND - LIBRARY / IMPORT BREAKDOWN
============================================

Source of truth: Backend/*.cs (excluding bin/ and obj/) and Backend/Backend.csproj

NuGet packages referenced (Backend.csproj)
------------------------------------------
- Microsoft.EntityFrameworkCore 10.0.10
- Microsoft.EntityFrameworkCore.Design 10.0.10 (dev-time only, PrivateAssets=all)
- Npgsql 10.0.3
- Npgsql.EntityFrameworkCore.PostgreSQL 10.0.3

Project settings: net10.0, Nullable=enable, ImplicitUsings=enable


1) ASP.NET Core hosting + middleware pipeline
---------------------------------------------
Files: Backend/Program.cs, Backend/Middleware/SessionAuthMiddleware.cs
(Namespaces come in via ImplicitUsings: Microsoft.AspNetCore.Builder/Hosting/Http/Routing,
 Microsoft.Extensions.Configuration/DependencyInjection/Hosting/Logging)

Used members:
- WebApplication.CreateBuilder(args)      -> creates host, config, DI container
- Configuration.GetConnectionString(...)  -> reads "DefaultConnection"
- Services.AddDbContext<AppDbContext>()   -> registers EF context
- Services.AddDataProtection()            -> registers cookie encryption services
- Services.AddScoped<PasswordService>()   -> per-request password service
- Services.AddScoped<SessionService>()    -> per-request session service
- Services.AddControllers()               -> MVC controller support
- app.UseHttpsRedirection()                -> dev-only HTTPS redirect
- app.UseAuthorization()                   -> authorization middleware slot
- app.UseDefaultFiles() / UseStaticFiles() -> serves React build from wwwroot
- app.UseMiddleware<SessionAuthMiddleware>() -> custom cookie-session auth gate
- app.MapControllers()                     -> maps attribute-routed endpoints
- app.MapFallbackToFile("index.html")      -> SPA fallback routing
- app.Run()                                -> starts the server

Types used in middleware:
- RequestDelegate, HttpContext, PathString
- PathString.StartsWithSegments("/api", StringComparison.OrdinalIgnoreCase)
- HttpMethods.IsOptions(...)               -> lets CORS preflight through
- Request.Cookies.TryGetValue / Response.Cookies.Delete
- StatusCodes.Status401Unauthorized
- HttpContext.Items["UserId"]              -> passes user id to controllers
- HttpContext.RequestAborted               -> cancellation token

Purpose: hosts the API + the compiled frontend, and blocks unauthenticated
/api requests except /api/auth/signup and /api/auth/login.

3) Microsoft.EntityFrameworkCore (EF Core)
------------------------------------------
Files: Program.cs, Data/AppDbContext.cs, Data/AppDbContextFactory.cs,
       Controllers/AuthController.cs, Controllers/api.cs, Services/SessionService.cs

Configuration / modeling:
- DbContext, DbContextOptions<T>, DbContextOptionsBuilder<T>
- DbSet<T>, Set<T>()                       -> Users, Products, Sessions
- OnModelCreating(ModelBuilder)
- Entity<T>().HasIndex(...).IsUnique()      -> unique Email, unique Product.Name, unique SessionKeyHash
- HasOne / WithMany / HasForeignKey / OnDelete(DeleteBehavior.Cascade)
  -> Session belongs to User; deleting a user deletes their sessions

Querying:
- AsNoTracking()      -> read-only queries (product list, /me lookup)
- AsTracking()        -> tracked query so an expired session can be deleted
- AsQueryable()       -> allows conditional Where composition for the filter
- Where(...), OrderBy(...)
- FirstOrDefaultAsync(...), AnyAsync(...), ToListAsync()

Writing:
- Add(...), Remove(...), SaveChangesAsync(cancellationToken)

Purpose: all database reads/writes for users, sessions, and products,
plus the unique-constraint enforcement at the schema level.

5) Microsoft.AspNetCore.DataProtection
--------------------------------------
Files: Program.cs (registration), Services/SessionService.cs (usage)

Used members:
- IDataProtectionProvider.CreateProtector("netcrud-session-key")
- IDataProtector.Protect(rawSessionKey)    -> encrypts value written to the cookie
- IDataProtector.Unprotect(cookieValue)    -> decrypts incoming cookie (throws if tampered)

Purpose: the session cookie never contains a raw usable token; it is encrypted
with an app key, and tampering causes Unprotect to throw and the session to fail.


6) System.Security.Cryptography
-------------------------------
Files: Services/PasswordService.cs, Services/SessionService.cs

Used members:
- RandomNumberGenerator.GetBytes(n)        -> 16-byte password salt; 32-byte session key
- Rfc2898DeriveBytes.Pbkdf2(...)           -> PBKDF2-SHA256, 100,000 iterations, 32-byte key
- HashAlgorithmName.SHA256
- CryptographicOperations.FixedTimeEquals  -> timing-attack-resistant hash comparison
- SHA256.HashData(bytes)                   -> hashes the session key stored in the DB

Purpose: password hashing/verification and session-token hashing.
Stored password format: "{iterations}:{base64 salt}:{base64 key}".
